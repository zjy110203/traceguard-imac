## 4. 结论（限定在本数据集与环境）

1. 传统基线在持久化故障场景 **4/4 假通过**；规则/C/D/E 全部降到 **0/4**。这是本轮复现的核心价值证据。
2. 主因准确率 15.8% → 47.4%（+6 例），但覆盖率仅 63.2%：规则引擎选择证据不足不下结论，
   必须与选择性准确率 75% 同看。
3. **D 与 C、E 与 C 在本批数据完全相同**：证据图与有序探针未带来额外主因命中；
   探针平均 2.63 次/样本、成功率 100%，但收益未体现。这是**负结果**，不解释为有效。
4. 与 RUN-007 历史数据（C=10/19、覆盖率 13/19）相比本轮 C=9/19、12/19，
   差异在 1 个样本内，属样本波动；不混用两轮数字，也不做统计显著性断言。
