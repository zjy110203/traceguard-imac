## 1. F/G 臂命名修正（§6.1）

| 旧名 | 新名（代码与后续统计） | 实际证据 | 结论 |
|---|---|---|---|
| `F_probe_aligned` | `F_probe_post_hoc_aware` | 54 条 `time_alignments` **全部 POST_HOC** | 事后探针回灌，不是 Run 内 ALIGNED 探针 |
| `G_probe_no_alignment` | `G_probe_unknown_time` | 54 条 `time_alignments` **全部 UNKNOWN** | 时间关系未知，不是"无对齐因果对照" |

- 归档 JSON 中 `ALIGNED = 0 / 108`，`run_internal_aligned_probes_produced = false`。
- `scripts/bench_pilot_run011_r1.py` 与 `scripts/bench_v5_run011_r1.py` 已改用新臂名；
  统计函数通过别名读取历史 JSON，原始文件保持不变。
- **本 Benchmark 没有产生 Run 内 ALIGNED 探针证据**，不得声称验证了"Run 内时间对齐价值"。

## 2. 实验结论收敛（§6.2）

| 臂 | 归档准确率 | 正确表述 |
|---|---|---|
| C_rule | 24/37 = 0.6486 | 规则基线 |
| E_probe_no_feedback | 24/37 = 0.6486 | 与 C 相同 |
| F_probe_post_hoc_aware（旧 F） | 26/37 = 0.7027 | 事后探针回灌后的小样本结果 |
| G_probe_unknown_time（旧 G） | 26/37 = 0.7027 | 与 F 相同 |
| H_llm_advisor | 23/37 = 0.6216 | LLM 成功 + 规则 Fallback 的**混合臂** |

- 只有 **2/37** 样本从 INCONCLUSIVE 变为 PROBABLE LOCATOR（均来自 LOC-NAME 场景）。
- 样本量 n=37，且 19 个失败场景、23 个执行场景；**不得描述为"时间对齐显著提高诊断准确率"**。
- 允许的表述：小样本下 F/G 相对 C 高 2/37，未见统计显著性检验，结论停留在观察层面。

## 3. LLM 统计拆分（§6.3）

| 指标 | 归档实测 | 说明 |
|---|---|---|
| LLM 成功调用率 | **21/37 = 0.5676** | `llm_arm.called = true` |
| JSON 非法率 | **16/37 = 0.4324** | `skipped = llm_error:invalid_json` |
| 规则 Fallback 率 | **16/37 = 0.4324** | 非法 JSON 后走确定性规则 |
| LLM 候选数量 | 63 条（21 次成功 × 每次 added=3） | 候选≠采纳 |
| LLM 成功子集准确率 | **13/21 = 0.6190** | 仅 `called=true` 的样本 |
| H 臂总体准确率 | 23/37 = 0.6216 | **混合口径**，不得当作 LLM 自身准确率 |
| Fallback 后系统准确率 | 0/16（未单独作为 LLM 成绩报告） | 单独归档在 `llm_advisor_statistics` |

`compute_statistics()` 新增 `llm_advisor_statistics` 分项，保留原 `H_llm_advisor` 数值供对照。

## 4. 其它指标口径核对（§6.4）

| 指标 | 当前实现 | 修订结论 |
|---|---|---|
| False Pass Rate | 旧脚本 `false_pass_rate_F` 实际统计"GT=PERSISTENCE 且预测非 PERSISTENCE/TIMING"，**不是** evaluator 定义的"GT 未持久化却判 PASSED" | 归档样本无 `verdict=PASSED` 的失败样本；按 evaluator 定义为 **0/37**。新统计键改为 `false_pass_rate`，并保留口径说明 |
| Abstention Rate | 0.1351（无机制预测占比） | 是弃权率；**不是**弃权正确率 |
| Abstention Accuracy | 未测量 | 需要"弃权时 GT 是否确实不可判定"的独立 GT，标记 `NOT MEASURED`，不得由 rate 代替 |
| Scenario Coverage | 旧值 1.0 = 19/19 失败场景 | 必须同时报告：执行场景 23、失败场景 19、正向控制 9 条样本已从主因准确率分母排除 |
| Probe Feedback Success Rate | 旧值 1.0 = 54/54 条反馈进入重新评估流程 | **不等于**假设更新率；实际更新 25/54 |
| Diagnosis Latency | 旧值均值 17.5ms | 仅诊断引擎调用；端到端执行均值 7874.8ms（含真实浏览器执行），两者不得混用 |
