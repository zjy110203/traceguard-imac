# 模块学习与实践路线（跨阶段能力成长路径）

- 用途：把 03 目录的分阶段学习路线整合为"按角色、按能力递进"的长期成长路径，供团队新成员与模块负责人规划学习。
- 与分阶段学习路线关系：03 目录按阶段组织（"进入某阶段前学什么"）；本文件按角色与能力层级组织（"某角色如何持续成长"）。
- 纪律：术语统一用 v1.1 正式名称；不把学习参考项目当作必须引入依赖。

## 一、角色与能力层级总览

| 角色（v1.1 目标用户/角色） | 核心能力目标 | 主要关联阶段 |
|---|---|---|
| 测试开发人员 | 建立/执行/维护自动化测试，审核用例 | 2、3、5、6、10 |
| 测试负责人 | 质量状态、覆盖、报告、失败分类 | 3、7、11、13 |
| 故障分析人员 | 理解失败原因、Evidence Graph、Hypothesis、Probe | 4、7、8、9 |
| 修复审核人员 | 控制测试资产变更风险、审核 Diff/审批 | 10 |
| 平台管理员 | 项目/权限/环境/凭证/资源 | 0、3、12 |
| Benchmark 研究人员 | 数据集、实验、指标、对照 | 1、11、12 |

能力层级：L1 基础工程 → L2 确定性执行 → L3 证据与诊断 → L4 Agentic Testing → L5 自愈与评测 → L6 泛化与交付。

## 二、L1 基础工程（阶段 0）

- 学习：Python/FastAPI/Vue3 工程、PostgreSQL 迁移、CI（Lint/Format/TypeCheck/UnitTest）、依赖锁定与兼容矩阵、pytest 基础、OpenTelemetry 可观测模型、安全基线（密钥不入库/最小权限/脱敏）。
- 实践：搭建可复现工程骨架；写第一组 pytest 单测与契约测试骨架；建立 C01～C12 Schema 目录。
- 完成标准：新环境可按文档复现；CI 有效；敏感配置不入库。
- 对应开发任务：阶段 0 工程初始化、P01 版本锁定。

## 三、L2 确定性执行（阶段 1～3）

- 学习：Playwright Browser/Context/Page/Locator/自动等待/网络监听/Trace Viewer；pytest Fixture/Scope/Parametrize/Hook/Plugin；Temporal Workflow/Activity/Retry 思想（不替换 Celery）；ReportPortal Launch/Test Item；Allure 结果模型。
- 实践：用 Playwright 为 TeamFlow"创建项目"写确定性用例（人工 TestCase + 人工 Oracle）；采集截图/Trace/Network；用 pytest 参数化覆盖五类故障；建 Task/Run/Step 本地模型。
- 完成标准：TestCase 可脱离 Agent 独立执行；Verdict 四状态与合法/非法样例可验证；`execution_status` 与 `test_verdict` 独立。
- 对应开发任务：阶段 2 执行内核、Oracle Manager、Verdict 聚合；阶段 3 编排与工作台。

## 四、L3 证据与诊断（阶段 4、7～9）

- 学习：OpenTelemetry Trace/Span/Event/Context/Resource；Langfuse LLM Trace（与业务 Evidence 的区别）；Event 幂等/Consumer Inbox/序号缺口；Evidence 分层（Raw/Normalized/Derived）；Diagnosis 八维模型与多 Hypothesis；LangGraph 条件边与 Checkpoint；Neo4j 属性图/Cypher（条件性）。
- 实践：搭建 Event 采集与幂等消费；把 Run/Step/Event/Evidence 关联成图；为一个失败写多 Hypothesis（含支持/反驳证据）；实现一个受控只读 Probe 与预算/权限校验。
- 完成标准：原始证据不可静默修改；相关不等于因果（不自动建 direct_causal）；证据不足输出 INCONCLUSIVE；Probe 越权被拒绝且留审计。
- 对应开发任务：阶段 4 Event/Evidence、阶段 7 Diagnosis v1、阶段 8 Graph、阶段 9 Active Diagnosis；P04/P05/P07/P12 确认。

## 五、L4 Agentic Testing（阶段 5～6）

- 学习：Browser Use REPL+CDP 与页面观察；Stagehand act/observe/extract 与 Action 重放；ATE 多 Agent 探索与 Brain/Hands 分离/JSON Intent（源码级）；LangGraph StateGraph/Checkpoint；Tool Gateway 权限模型；ATE Action Tape→spec 转写；Healenium Locator 稳定性。
- 实践：实现 Explorer Agent 骨架（LLM 出 JSON Intent + 确定性 dispatch + 操作留痕）；生成 Exploration Trace；实现一个 Compiler 原型（Normalizer/Action Extractor/Locator Resolver/Assertion Constructor/Oracle Binder/Stability Validator）；候选回放稳定性验证。
- 完成标准：自然语言目标可在授权范围内探索；Trace 完整可追溯；候选可脱离 Explorer 回放；不稳定候选不晋升；Oracle 审批不可绕过；不把探索成功当测试通过。
- 对应开发任务：阶段 5 Explorer、阶段 6 Compiler、P02 集成 PoC。

## 六、L5 自愈与评测（阶段 10～11）

- 学习：Healenium Locator Healing（候选匹配/反馈闭环）；Stagehand 动作恢复；Hercules healing（仅学设计，AGPL 禁复制代码）；Oracle 保护与 Assertion Preservation；CAS 原子晋升与版本冲突；Inspect AI Task/Dataset/Solver/Scorer；AgentLab Study/并行/复现；BrowserGym Task/Episode/Reward；A～E 对照与消融；指标口径。
- 实践：为一个 Locator 变化生成修复候选；实现断言保护检查（assertion_id/语义/Oracle 绑定/required/evaluation_rule/覆盖范围/预期来源）；沙箱回放 + 审批 + 回归 + CAS 晋升 + 回滚；设计一组 A～E 对照实验。
- 完成标准：删除断言/修改 Oracle 被拒绝；沙箱或回归失败不晋升；版本并发冲突被阻断；INCONCLUSIVE 不计 PASSED；指标有统计单位/分子分母/排除条件。
- 对应开发任务：阶段 10 Self-Healing、阶段 11 UI-FaultBench、P08/P09 确认。

## 七、L6 泛化与交付（阶段 12～13）

- 学习：OWASP ZAP 被动/主动扫描与 API（安全扫描 ≠ UI 诊断）；Juice Shop 靶场；Browser Use 安全约束（域名限制/脱敏/prompt injection）；Stagehand 页面变化适应；SSRF/DNS Rebinding 防护；三级 CI 门禁；全链路证据链。
- 实践：在 1～2 个授权外部应用验证探索与执行；完成安全测试与性能/稳定性实测；按三级门禁执行回归；准备十个最终演示场景的执行证据。
- 完成标准：越权访问被阻断；凭证不泄漏；性能有实测；PR/Nightly/Release 门禁按定义执行；十场景有执行证据；发布包/文档/已知限制完整。
- 对应开发任务：阶段 12 泛化与安全、阶段 13 集成交付、P10/P11 确认。

## 八、按角色的推荐学习顺序（快速索引）

| 角色 | 建议顺序 |
|---|---|
| 测试开发人员 | L1 → L2 → L4（Explorer/Compiler 部分）→ L5（自愈审核协作） |
| 测试负责人 | L2 → L3（诊断概览）→ L5（评测）→ L6（报告与门禁） |
| 故障分析人员 | L2 → L3（重点）→ L4（Explorer Trace 理解）→ L5（对照实验） |
| 修复审核人员 | L3 → L5（断言保护/CAS/回滚重点） |
| 平台管理员 | L1 → L2（编排）→ L6（隔离/配额/安全） |
| Benchmark 研究人员 | L2 → L3 → L5（评测）→ L6（外部泛化） |

## 九、实践资源与纪律

1. 每个能力层配合对应阶段的 v1.1 交付物实践，不用玩具 Demo 替代真实链路验证。
2. 开源项目源码仅作学习，不在 TraceGuard 正式源码目录复制；需克隆时用 `TraceGuard-开源项目调研/.research-tmp/` 临时目录。
3. 学习过程中形成的新发现按"借鉴决策台账"登记，不直接改 v1.1 设计。
4. 边界口诀：Playwright≠Explorer、Browser Use≠执行内核、Langfuse Trace≠业务 Evidence、ReportPortal 分类≠根因、Healenium≠安全自愈、ZAP≠UI 诊断、Neo4j≠必选、Checkpoint≠业务权威。
