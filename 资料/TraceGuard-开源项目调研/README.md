## 关键结论速览

1. **没有单一项目覆盖 TraceGuard 全链路**——自建整合架构必要。
2. **两者判定机制不同，但均缺独立 Trusted Oracle**：ATE 靠 LLM 分析探索结果并自报 PASS/FAIL；Hercules 无独立 Assertion Agent、最终 `is_passed` 仍由 Planner 提供，但具备默认注册的 API 确定性断言、可选 UI 断言与报告期断言账本覆盖——反向印证 TraceGuard"Oracle 独立 + 确定性 Verdict + 可信预期绑定"冻结原则。
3. **Hercules 为 AGPL-3.0**——强 copyleft，不得复制源码，仅学设计，待法律评估。
4. **Neo4j 非必选**——Evidence Graph 首期用 PostgreSQL，P12 待确认。
5. **本轮 19 个项目无一被批准采用**——此处仅指 **R1 研究未批准任何新增依赖**，研究完成 ≠ 批准采用；**不撤销 v1.1 已选定的 Playwright、pytest、OpenTelemetry、Browser Use、LangGraph 等技术**（其版本与边界仍按 P01～P03、RV-03 待确认）。

## 边界纪律（贯穿全部文档）

Playwright≠Explorer Agent；Browser Use≠正式执行内核；Langfuse LLM Trace≠业务 Testing Evidence；ReportPortal 失败分类≠根因诊断；Healenium Locator Healing≠完整安全自愈；BrowserGym≠测试管理平台；OWASP ZAP 安全扫描≠UI 测试诊断；Temporal≠替换 Celery；Neo4j≠必须采用；LangGraph Checkpoint≠业务状态权威。
