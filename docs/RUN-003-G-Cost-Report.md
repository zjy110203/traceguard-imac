## 成本控制机制（已实现）

1. `TokenUsageTracker.estimate_cost()`：逐次记录估算成本；
2. `should_skip_llm()`：当日估算成本 ≥ 预算 → 暂停新的非必要调用，规则兜底；
3. 有限重试（≤2 次）+ 请求超时（60s）+ 失败熔断；
4. Pro 模型需显式升级原因（防止默认全走 Pro 拉高成本）。
