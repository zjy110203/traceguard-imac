## 5. 升级与回滚

- 后端：调整 `requirements*.txt` 约束 → 重装 → 跑全测试；失败则恢复上一版约束。
- 前端：调整 `package.json` → `npm install` → `npm run build`；`package-lock.json` 保证可复现。
- 破坏性升级需记录影响契约与模块，禁止在未跑通测试前合并。
